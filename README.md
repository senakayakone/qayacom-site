# qayacom.com

Site statique (GitHub Pages, sans outil de build).

- `/` : Qayacom, développement d'applications mobiles à Vientiane
  (`assets/qayacom.css`, `assets/qayacom.js`).
- `/laoalphabet/` : site de l'app Lao Alphabet for Kids, avec l'aide
  (`#support`, adresse d'assistance de l'App Store).
- `/confidentialite/` : politique de confidentialité.
- `/laoalphabet/privacy-policy/` et `/contact/` : anciennes adresses,
  redirigées.

Langues : anglais dans le HTML, français et lao dans les scripts
(`data-i18n`). Le lao reste à faire relire par un locuteur natif.
Aperçu local : `python3 -m http.server` puis http://127.0.0.1:8000/
