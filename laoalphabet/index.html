Handwriting

Write every letter the right way

Lao letters are written in one stroke, starting with the loop. The app shows the way, then checks the child's tracing.

  • Start dot and direction shown by an animated pencil
  • Automatic check of the tracing, with 0 to 3 stars
  • Dictation mode to write from memory
